# Logic Assistant — сборка мода под Android и ПК

Исходный `.jar`, который вы прислали, был скомпилирован **только под ПК**
(обычные `.class`-файлы). Mindustry на Android грузит моды через `DexClassLoader`,
которому нужен файл `classes.dex` внутри `.jar` — такого файла в вашей сборке не было,
поэтому на телефоне мод не появлялся/не запускался.

Я восстановил исходный код мода (`ai.logicassistant.*`) и положил его в официальный
шаблон Java-мода Mindustry (`Anuken/MindustryJavaModTemplate`) с готовым
GitHub Actions workflow, который автоматически собирает **кроссплатформенный**
`.jar` (ПК + Android) на серверах GitHub — там уже есть Android SDK и `d8`, которых
нет в этой песочнице, поэтому собрать финальный файл нужно именно через GitHub.

## Как получить рабочий .jar (5 минут, ничего локально ставить не нужно)

1. Зайдите на github.com, создайте новый **публичный** репозиторий (например `logic-assistant`).
2. Загрузите в него всё содержимое этой папки/архива (через "Add file → Upload files"
   в браузере — просто перетащите все файлы и папки, включая скрытую `.github`).
3. Откройте вкладку **Actions** репозитория — сборка "Build Mod" запустится сама.
4. Дождитесь зелёной галочки (обычно 1-2 минуты).
5. Откройте завершённый запуск → внизу страницы, в разделе **Artifacts**, скачайте
   файл с именем вашего репозитория — это zip с готовым `logic-assistant.jar` внутри.
6. Распакуйте и получите `logic-assistant.jar` — он работает и на ПК, и на телефоне.

## Установка в игру

- **На телефоне**: Mindustry → Mods → Import mod → выберите `logic-assistant.jar`
  (или просто скачайте его прямо с телефона по ссылке на Artifact — Mindustry сам
  предложит импортировать).
- **На ПК**: так же через меню модов, или киньте jar в папку модов Mindustry.

Если что-то не соберётся — пришлите мне текст ошибки из вкладки Actions, разберёмся.
